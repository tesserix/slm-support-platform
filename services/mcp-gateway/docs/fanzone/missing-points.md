# My points didn't update after the match

Points settle within 5 minutes of the match ending in 95% of cases. If they haven't shown up after 30 minutes, one of these things is happening:

## The match is still "in scoring"

When stumps are drawn, the official scoring feed needs a few minutes to confirm the result. FanZone won't settle predictions on a match until the feed marks it final. Look at the match card on the home page — if it still shows "Live" or "Awaiting result", points are pending by design.

## You joined a live battle room mid-innings

Predictions placed after the toss don't carry the 1.5× live-battle multiplier. The base score still applies though, so you should see *some* points credited. If you see zero, file a support ticket so we can audit the predictions on that case.

## Your wallet display is stale

The points balance in the header is cached for performance. Hard-refresh (Cmd-Shift-R on Mac, Ctrl-F5 on Windows) — if the number jumps, that was the cache, not a points bug.

## Something genuinely failed

If you have the **case ID** from a support chat, share it. Otherwise quote your **user_id** and the **match ID** (visible in the URL of the match detail page) and we'll pull the audit trail for that prediction.
